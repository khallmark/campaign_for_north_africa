CAMPAIGN FOR NORTH AFRICA

This is a VASSAL module for Campaign for North Africa, SPI's "super-detailed,
intensive simulation specially designed for maximum realism.

Map, counters, charts and rules have all known errata applied.

See Changelog for details on versions.

SOME KEYBOARD SHORTCUTS

  CTRL + Numeric +  - Increase main map size
  CTRL + Numeric -  - Decrease main map size
  CTRL+R            - Return unit to organization chart / map (shows or hides a minefield counter)
  CLTR+L            - change label for marker that needs an ID change name for the German KG unit with no name
  CLTR+C            - clone a marker (also applies to the German KG unit with no name)

PLACING UNITS

When you have a game open, clicking on the Organization Charts (with units)
button will bring up the unit organization charts with the counters for each
formation on the chart.

Units can be dragged from a chart to the main map and vice versa - you can
also right click a unit on the main map and select Return to Organization
Chart.

If no game is loaded, then no charts and units are displayed so use the
Organization Charts (with units) button to view the charts.


=================================================================

USING MINEFIELD COUNTERS

To place Dummy or Real mines drag from the Markers tray then CTRL+R to hide
- this shows the Unknown image to the other side, while displaying the Unknown
image in the corner for the owning side.


=================================================================

LABELS

The Markers window includes a Labels panel. This contains a set of labels
which can be placed on a map and have their text set by the player. There are
three different font sizes to choose from, and each one also has a version
which adds a white background to the text entered by the player.

When a label is on the map hold down the SHIFT key when clicking it to select it.

Players can also use simple HTML when entering text to specify different
colors, fonts and sizes, or more complex HTML to add tables and other
formatting. See the article in View From The Trenches 101 (available from
https://www.vftt.co.uk/indexs.asp) for a detailed tutorial on what can be done
using HTML in labels.
